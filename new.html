一鍵發布｜新建 Repository

自動建立公開 Repository、上傳 ZIP 網站檔案，並設定 GitHub Pages。

請勿將 Token 公開或寫入程式碼；發布前請確認 ZIP 不含私人資料。

新建模式只允許建立全新 Repository。同名已存在時立即停止，絕不覆蓋原網站；請切換至「一鍵修改」。

ZIP 必須包含 index.html，可包在單一最外層資料夾內。ZIP ≤ 25 MB，解壓後總量 ≤ 50 MB，單檔 ≤ 20 MB，最多 500 個檔案。

GitHub Token 設定差異與取得路徑

「一鍵發布」與「一鍵修改」使用不同的 Token 類型，請依功能選擇。

一鍵發布｜新建 Repository

Tokens (classic)：適用於自動建立公開 Repository 並上傳網站。

GitHub 個人頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)

設定：Expiration 建議 30 days；Select scopes 勾選 public_repo。

前往 Classic Token 建立頁面 ↗

一鍵修改｜更新既有 Repository

Fine-grained tokens：適用於只授權指定 Repository 進行更新。

GitHub 個人頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token

設定：Repository access 選 Only select repositories；Contents: Read and write。若需要由平台設定 Pages，另需 Administration: Read and write。

前往 Fine-grained Token 建立頁面 ↗

GitHub Pages 設定與確認路徑

Repository → Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save

平台會嘗試自動啟用 Pages；若設定失敗，請依上方路徑檢查。若實際分支不是 main，請選擇對應分支。

安全提醒：Token 請勿放入公開程式碼、截圖或分享給他人；使用完畢可在 GitHub 撤銷。Classic Token 的 public_repo 權限可能涵蓋帳號可存取的其他公開 Repository。
